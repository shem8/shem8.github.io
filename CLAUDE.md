# blog.shem.dev

See README.markdown for how content is organized. Use `npm run new <post|talk|project|press|job> "Title"` to add items.

Content rules:
- Don't invent descriptions, numbers or links, and don't guess URLs.
- Only list talks that happened or are scheduled, not ones merely submitted or accepted.
- Use private mail only to verify facts; never publish it.
- Don't use family or kids' photos unless Shem approves each one. Blur customer names and emails in screenshots.
- `npm run deploy` makes changes live. Shem approves before anything is published.
